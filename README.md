# AcademyPrep

AcademyPrep is an iOS application built with UIKit to help candidates prepare for law enforcement academies.

The project started as a CHP (California Highway Patrol) Academy Prep tracker and is being developed as a learning project while studying UIKit, iOS development, and software architecture.

## Current Features

- CHP APP workout schedule
- Calendar-based workout tracking
- Workout completion tracking
- Program progress tracking
- Monthly fitness logs
- Custom workouts
- Local data storage

## Future Features

- Core Data persistence
- Apple Watch support
- Progress charts and analytics
- Written test resources
- Background investigation preparation tools
- Additional academy programs
  - Sheriff Academy
  - Police Academy
  - Corrections Academy

## Tech Stack

- Swift
- UIKit
- MVC Architecture
- UserDefaults (current persistence)
- Xcode

## Project Goals

This project serves two purposes:

1. Help academy candidates stay organized and track progress.
2. Document my journey learning UIKit and iOS development.
